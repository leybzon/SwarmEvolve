The Deterministic Crucible

Constraining the AI Mind

  • Strict Physics: 2D arena (1000×1000), instantaneous movement, synchronous combat resolution
  • High Stakes: Firing incurs 8-tick cooldown. Mutual destruction if both fire simultaneously
  • Information Asymmetry: Drones see enemy positions, but not enemy cooldowns
  • Hardware Constraints: Only 16 floats of persistent memory + 4-float radio broadcast per tick (GPU compatibility)
struct AllyState {
    float x, y;           // Position
    int cooldown;         // Visible to teammates
    bool alive;
};

struct EnemyState {
    float x, y;           // Position visible
    bool alive;
    // cooldown HIDDEN - must be inferred!
};
To evolve on GPUs, we need deterministic physics and strict memory limits. The cooldown asymmetry creates a fog-of-war that forces tactical innovation.

Starting & Restarting Evolution

Guardrails for Artificial Genetics

  • The Barrier: Untrusted AI code hallucinates infinite loops (while(true)) that hang GPU simulations
  • AST Injection: Python orchestrator injects loop guards directly into C++ AST before compilation 
    // LLM writes:
while(searching) { ... }

// Orchestrator injects:
int _guard = 0;
while(searching) {
    if(++_guard > 1000) break;
    ...
}
  • Restarting: When code crashes, we isolate the error, log stack trace, and feed it back to LLM for retry
  • Mass Scale: Evaluates 10-100 matches in parallel (up to 2,000 drones simultaneously)
The biggest challenge was making untrusted AI code safe for GPU execution. We use AST injection to add safety bounds, and automatic restart loops when mutations fail.

Complexity & Fragility

The Cost of Intelligence

  • Capability requires complexity: Each major tactic cost ~30-40 lines of code
  • Team A's fragility: 204-line champion was a "local optimum trap" - every mutation broke critical logic
  • Over-optimization risk: Early perfection creates evolutionary dead-ends
There's a brutal tradeoff. To win, Team B needed to write 3x more code. But Team A's complexity made it fragile. Every time the LLM tried to improve Team A, it broke something critical and lost -1.0 fitness. This is why evolution sometimes favors scrappy underdogs over over-optimized champions.
