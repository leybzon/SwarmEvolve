# Security Policy

## Threat model

SwarmEvolve compiles and runs **untrusted** code generated by large language
models. The primary threats, ordered by impact:

1. **Sandbox escape** — LLM-authored AI code reading/writing host filesystem,
   opening network sockets, or executing syscalls outside the allowed set.
2. **GPU denial of service** — infinite loops triggering the GPU TDR (Timeout
   Detection and Recovery) watchdog and destabilizing the host GPU driver.
3. **Resource exhaustion** — memory, CPU, PID, or wall-clock abuse causing
   orchestrator lockup or denial of service.
4. **Supply-chain compromise** — malicious dependency pulled via pip or a
   base Docker image drift.
5. **Secret exfiltration** — API keys leaked through logs, traces, or
   experiment archives.

## Defenses (implemented across milestones)

| Layer                 | Milestone | Mechanism |
|-----------------------|-----------|-----------|
| POD-only AI ABI       | M1        | No pointers to dynamic storage cross the boundary |
| Compile-time banned-token lint | M0 | `scripts/lint_ai_tokens.py` + pre-commit hook |
| Loop-guard injection  | M6        | AST-level rewrite of every loop with a 1000-iter cap |
| Process sandbox       | M8        | Rootless container, `--network=none`, seccomp, cap-drop |
| Resource limits       | M8        | cgroup memory/PID/CPU caps; 10 s wall-clock timeout |
| Determinism pinning   | M4        | Seeded PRNG; golden trace hash |
| Dependency pinning    | M0        | `pyproject.toml` + Dependabot + `pip-audit` |
| Secret redaction      | M10       | `llm_client.py` redacts keys before logging |

## Reporting a vulnerability

**Do not open a public GitHub issue for security problems.**

Email the maintainer privately (see repository owner profile for contact
address). Include:

- A minimal reproduction (script, input, expected vs observed behavior).
- Affected commit SHA / release tag.
- Your assessment of impact and any suggested mitigation.

We will acknowledge within 7 days and aim to provide a fix or mitigation
within 90 days. We will coordinate a public disclosure with you.

## Out of scope

- Bugs in LLM-authored AI strategies (these are research artifacts, not
  production code).
- Issues requiring physical access to the host running the evolutionary loop.
- Denial-of-service tests that are already covered by the sandbox escape
  suite in `tests/test_sandbox_escape.py` (these are expected to be safely
  contained).
